        Kurulum

        1. Hesap ve property aç. analytics.google.com · Property adı Anthifel, saat dilimi Londra, para birimi GBP.
        2. Web veri akışı ekle: anthifel.com Google G-XXXXXXXXXX biçiminde bir Measurement ID verir.
        3. Aşağıdan kodu üret, sayfaya koy. Kod </head>'den hemen önce durur. Sayfalar tek dosya olduğu için kaynağa girer, üretilmiş çıktıya değil.

        Settings

        Keys this browser holds, and where the ones it does not hold actually live.

        This page is served from a public address. Nothing secret is written into it, which is why there is no field here for the API keys the server uses — those live in Apps Script and never travel to a browser. The one key below is the exception, because it is the key that proves this browser is allowed to ask.

        Panel key

        The shared secret the blog editor sends with every request — the same string as DASH_TOKEN in Apps Script → Project Settings → Script Properties. It is kept in this browser only. Entering it on another machine is one paste; publishing it would hand over write access to the repository.

        What we ask the model

        The two briefs the blog editor sends to Gemini: one to write the piece, one to draw its cover. They are stored next to the key they are spent with, in Apps Script, not in this page. Leave a field empty and the built-in brief comes back.

        House style is not a field. No em dash, no emoji, no invented client, no price, and the four service names left in English: those are appended to whatever is written here, so an edited brief cannot drop the rules the rest of the site follows.

        Who the reader is and what a piece is for. The title, the pillar and the plan note are added underneath it.
        The look. The title and standfirst are added as the subject. Covers are written as WebP in four crops.
